# Header Layout Constraints (Important)

The current header layout shown below has already been implemented and should remain the foundation for the Security Analytics page.

`` 
Security Analytics
                                         Customer ▼  Configure Filter    7d | 30d | 90d | 1y    Refresh    Auto: Off ▼
Executive posture overview...    
```

This layout is clean and balanced.

Future additions to the dashboard must preserve this layout as much as possible.

## Header Placement Rules

Do not redesign the header.

Do not move the existing controls to another row.

Keep the controls in the header area.

The current controls are:

* Customer
* Configure Filter
* Time Range
* Refresh
* Auto Refresh

These controls should remain grouped together.

---

# Space Optimization Rules

If additional controls need to be added in the future, first reduce the width of the existing controls before changing their placement.

## 1. Time Range

Replace the segmented selector:

* 7d
* 30d
* 90d
* 1y

with a compact dropdown.

Example:

```text
30d ▼
```

Supported values remain:

* Last 24 Hours
* Last 7 Days
* Last 30 Days
* Last 90 Days
* Last Year

This is only a UI optimization.

The filtering logic must remain exactly the same.

---

## 2. Refresh Button

Replace

```text
↻ Refresh
```

with

```text
↻
```

Use only the refresh icon.

Provide a tooltip:

```text
Refresh Dashboard
```

The functionality must remain unchanged.

---

## 3. Customer Filter

The current centered Customer filter should remain where it is if there is enough space.

However, if future controls require additional horizontal space, it is acceptable to move the Customer filter into the same control group as the other filters.

If this becomes necessary, use the following order:

```text
Customer ▼

Configure Filter

Last 30 Days ▼

↻

Auto: Off ▼
```

All controls must remain on the same row.

Do not move the Customer filter below/above the header.

Do not place it above or below the dashboard cards.

---

# Future Header Expansion

If future phases introduce additional controls, follow this priority:

1. Convert the Time Range selector to a dropdown.
2. Convert Refresh to an icon-only button.
3. Move the Customer filter next to the other header controls (only if necessary).
4. Only after these optimizations should any additional header controls be introduced.

The goal is to preserve the clean appearance of the current dashboard while making room for future enhancements.

---

# Preserve Existing Functionality

These layout refinements must not modify:

* Dashboard calculations
* Security Score
* Executive Cards
* Charts
* Device Inventory
* Existing filtering behavior
* Customer filtering logic
* Time filtering logic
* Refresh functionality
* Auto Refresh functionality

This section only defines layout constraints for the header and should be treated as a permanent design guideline for all future phases.
