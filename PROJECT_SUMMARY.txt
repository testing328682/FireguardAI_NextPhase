FirewallGuard AI — Project Summary
===================================
Last updated: 23 June 2026

WHAT IT IS
----------
Multi-tenant SaaS platform for continuous SonicWall firewall security posture
analysis. Upload a Tech Support Report (TSR) or connect via SonicOS API, and
FirewallGuard AI returns a scored, prioritised set of findings, correlated
attack paths, firmware vulnerability intelligence, and reports.

STACK
-----
Backend:  Python 3.12, FastAPI, SQLAlchemy 2.0, PostgreSQL, Redis, Celery
Frontend: React 18 + TypeScript + Vite + Tailwind (dark-theme security console)
Deploy:   Docker Compose (dev), target Kubernetes on AWS (prod)

ARCHITECTURE
------------
firewallguard/          Analysis engine (pure Python, no DB dependency)
  tsr/                  TSR reader + parser (60+ section parsers)
  rules/                Rule engine + ~68 evidence-gated detection rules
  intelligence/         PSIRT/CVE matching, attack-path correlation
  analytics/            0-100 scoring, A-F grading, config drift
  report/               PDF (ReportLab), CSV, JSON exports
  pipeline.py           Orchestrator: parse -> rules -> firmware -> correlate -> score

app/                    FastAPI service layer
  models.py             SQLAlchemy ORM (multi-tenant) + configured flag, hidden_severities
  security.py           JWT, bcrypt, RBAC, MFA, lockout, API tokens
  rule_engine.py        CEL evaluator, _SYSTEM_RULE_CEL defaults,
                        check_firmware_compliance(), seed_system_rules()
  findings_sync.py      Persist pipeline findings; auto-reopen/resolve lifecycle
  tasks.py              Celery workers; firmware check runs before storing counts
  routers/              Auth, devices (registration + connect + visibility),
                        findings (snapshot-based + category + analysis_id),
                        rules (modal creation + categories), platform, etc.

frontend/               React SPA
  Devices.tsx           Device list with modal registration, Configure modal,
                        row click to detail, fixed action menu
  DeviceDetail.tsx      Device info card, TSR history with delete, upload new TSR,
                        Go to Findings button
  FindingsExplorer.tsx  Device-centric: device list → device-specific view with
                        TSR selector, comparison modal, visibility settings,
                        category filter, clickable KPI cards
  UploadPanel.tsx       TSR upload for pre-registered devices
  Rules.tsx             Rule library with modal-based creation + category dropdown
  Dashboard.tsx         Fleet KPI cards, trend chart, compliance bars
  Platform.tsx          Cross-tenant operator dashboard
