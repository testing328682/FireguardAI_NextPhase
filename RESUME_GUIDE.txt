6. KEY FEATURES — HOW TO USE
─────────────────────────────

DEVICE ONBOARDING (two-step):
    Devices → + Add Device (modal) → enter name + serial + confirm serial → Register
    Device appears as "Not Configured" → click ⋯ → Configure…
    Choose: Upload TSR or Connect via API → serial validated → device becomes Configured

DEVICE DETAILS:
    Click any configured device row → Device Details page
    Shows: name, serial, model, firmware, status, TSR count, date added, last analysis, score/grade
    TSR History table with delete per TSR
    "Go to Findings" button, "Upload New TSR" button

FINDINGS (device-centric):
    Findings page → shows device list with per-device metrics (score, severity counts, open, last scan)
    Click a device → device-specific view with:
      - TSR dropdown (select which analysis to view, defaults to latest)
      - Export PDF (Technical Report) + CSV
      - Compare Findings button (if ≥2 TSRs)
      - Configure Filter button (visibility settings)
      - Clickable KPI cards (click severity/status to filter findings)
      - Category column + filter
      - Full findings table with bulk actions

TSR COMPARISON:
    Compare Findings → pick Baseline + Newer TSR → Compare
    Summary: New/Resolved/Config Changes/Score Δ counts
    Detailed Report: side-by-side table showing ALL findings from both TSRs
      with severity, category, and status per TSR
    Print/PDF button for browser-native PDF export

VISIBILITY SETTINGS:
    Main findings page → Configure Filter (global): per-severity On/Off toggles
    Device findings → Configure Filter (device): per-severity toggles with "Inherit from Global" checkbox
    Device settings override global; when inheriting, toggles are disabled

8. COMMON ISSUES & FIXES
─────────────────────────
"Internal Server Error" on any page:
    → Database schema may be stale (missing columns)
    → Run: docker compose exec api alembic upgrade heads
    → Or add columns manually via psql (see section 4)

No devices showing / counts show 0:
    → Register and configure a device first
    → Upload a TSR to trigger counts population

Findings counts don't match between pages:
    → The findings page now only counts active-status findings (open/acknowledged/in_progress)
    → The devices page queries live finding counts

CEL conditions not working:
    → String values with spaces need quotes: "SonicOS 7.0.1" not SonicOS 7.0.1

Docker on Windows (docker not found):
    → Use full path: C:\Program Files\Docker\Docker\resources\bin\docker.exe

Port 8000 not responding:
    → Windows Docker networking quirk — use port 8080 (nginx) instead

Alembic "Multiple head revisions" error:
    → Use: docker compose exec api alembic upgrade heads
    → Or target specific revision: docker compose exec api alembic upgrade c3d4e5f6a7b8
